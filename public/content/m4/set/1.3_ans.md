# เฉลยใบงานที่ 1.3: ชนิดของเซต

---

$1.$ เซตของจำนวนนับที่หารด้วย $2$ ลงตัว
**ตอบ:** **เซตอนันต์** (เพราะมี $2, 4, 6, 8, \dots$ ไปเรื่อยๆ ไม่มีที่สิ้นสุด)

$2.$ เซตของสุนัขที่บินได้
**ตอบ:** **เซตว่าง** (เพราะไม่มีสุนัขที่บินได้บนโลกนี้ จำนวนสมาชิกคือ $0$)

$3.$ $\{1, 3, 5, \dots, 99\}$
**ตอบ:** **เซตจำกัด** (เพราะจุด $\dots$ มีตัวปิดท้ายคือ $99$ แปลว่าเรารู้จำนวนที่แน่นอน)

$4.$ $\{x \mid x \text{ เป็นจำนวนเต็ม และ } x > 5\}$
**ตอบ:** **เซตอนันต์** (เพราะจำนวนเต็มที่มากกว่า $5$ มี $6, 7, 8, 9, \dots$ ไปเรื่อยๆ)

$5.$ $\{\emptyset\}$
**ตอบ:** **เซตจำกัด** (ไม่ใช่เซตว่าง! เพราะมีสมาชิก $1$ ตัว คือตัวสัญลักษณ์ $\emptyset$)
