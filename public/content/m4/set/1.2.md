# 1.2 วิธีการเขียนเซต

หลังจากที่เรารู้จักเซตแล้ว ว่ามันคือการจัดกลุ่มสิ่งของ วันนี้เราจะมาดูว่า **"วิธีการเขียนเซต"** ทางคณิตศาสตร์เขาเขียนกันยังไง ซึ่งมี 2 วิธีหลักๆ ครับ

## 1. การเขียนเซตแบบแจกแจงสมาชิก (Tabular Form)
วิธีนี้ง่ายและตรงไปตรงมาที่สุด คือ **มีตัวอะไรบ้าง ก็เขียนเรียงออกมาให้หมดเลย** โดยคั่นแต่ละตัวด้วยเครื่องหมายจุลภาค (,) และครอบด้วยปีกกา `{ }`

**ตัวอย่าง:**
- $A$ เป็นเซตของจำนวนนับที่น้อยกว่า 5 
  ➡️ $A = \{1, 2, 3, 4\}$
- $B$ เป็นเซตของพยัญชนะในคำว่า "คณิต" 
  ➡️ $B = \{ค, ณ, ิ, ต\}$

> ⚠️ **กฎข้อควรระวัง:** 
> 1. สมาชิกซ้ำกัน ให้เขียนแค่ **ครั้งเดียว** เช่น คำว่า "สระสะ" ➡️ $C = \{ส, ร, ะ\}$
> 2. ถ้าสมาชิกมีเยอะมาก แต่มีรูปแบบชัดเจน เราสามารถใช้ **จุด 3 จุด (...)** ละไว้ในฐานที่เข้าใจได้ เช่น $D = \{1, 2, 3, \dots, 100\}$

---

## 2. การเขียนเซตแบบบอกเงื่อนไข (Builder Form)
วิธีนี้เหมาะกับเซตที่มีสมาชิกเยอะมากๆ จนเขียนไม่ไหว หรือไม่สามารถแจกแจงได้ เราจะใช้ตัวแปร (เช่น $x$) มาเป็นตัวแทนสมาชิก แล้วเขียนเงื่อนไขกำกับไว้ด้านหลังเครื่องหมาย ขีดตั้ง `|` (อ่านว่า "โดยที่")

**รูปแบบ:** $\{x \mid \text{เงื่อนไขของ } x\}$

**ตัวอย่าง:**
- $E = \{x \mid x \text{ เป็นจำนวนเต็มบวกที่น้อยกว่า 5}\}$
  *(อ่านว่า: E เป็นเซตของ x โดยที่ x เป็นจำนวนเต็มบวกที่น้อยกว่า 5)*
  ถ้าแปลกลับไปเป็นแบบแจกแจงก็จะได้ $\{1, 2, 3, 4\}$ นั่นเอง!
