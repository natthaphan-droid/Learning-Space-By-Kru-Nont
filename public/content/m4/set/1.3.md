# 1.3 ชนิดของเซต

เราเรียนรู้วิธีการเขียนเซตไปแล้ว ตอนนี้เรามาแบ่งแยก "ชนิด" ของเซตกันบ้างครับ ในคณิตศาสตร์เราแบ่งเซตออกเป็น $3$ ชนิดหลักๆ ตาม "จำนวนสมาชิก" ของมันครับ

## 1. เซตจำกัด (Finite Set)
คือ เซตที่เรารู้ **"จำนวนสมาชิกที่แน่นอน"** ว่ามีกี่ตัว (สามารถนับได้ว่ามี $5$ ตัว, $10$ ตัว, หรือ $1$ ล้านตัว)

**ตัวอย่าง:**
- $A = \{1, 2, 3, 4, 5\}$ (นับได้ $5$ ตัว เป็นเซตจำกัด)
- $B = \{x \mid x \text{ เป็นชื่อเดือนในหนึ่งปี}\}$ (นับได้ $12$ ตัว เป็นเซตจำกัด)
- $C = \{1, 2, 3, \dots, 100\}$ (มีจุด $\dots$ ก็จริง แต่มันไปจบที่ $100$ นับได้ $100$ ตัว เป็นเซตจำกัด)

## 2. เซตอนันต์ (Infinite Set)
คือ เซตที่มีสมาชิกเยอะมากๆ **"นับไม่ถ้วน"** ไม่มีจุดสิ้นสุด หาตัวสุดท้ายไม่ได้

**ตัวอย่าง:**
- $D = \{1, 2, 3, 4, \dots\}$ (จุด $\dots$ อยู่ด้านหลัง และไม่มีตัวปิดท้าย แปลว่าไปเรื่อยๆ ไม่มีที่สิ้นสุด เป็นเซตอนันต์)
- $E = \{x \mid x \text{ เป็นจำนวนเต็ม}\}$ (จำนวนเต็มมีทั้งบวก ลบ ศูนย์ ไปเรื่อยๆ เป็นเซตอนันต์)

## 3. เซตว่าง (Empty Set)
คือ เซตที่ **"ไม่มีสมาชิกเลย"** แม้แต่ตัวเดียว! (จำนวนสมาชิกเท่ากับ $0$)
- สัญลักษณ์ที่ใช้: $\{\}$ หรือ $\emptyset$ (อ่านว่า ไฟ, Phi)

**ตัวอย่าง:**
- $F = \{x \mid x \text{ เป็นชื่อเดือนที่มี } 32 \text{ วัน}\}$ (ไม่มีเดือนไหนมี $32$ วัน ดังนั้น $F = \emptyset$)

> ⚠️ **ข้อควรระวังสุดฮิตในข้อสอบ:** 
> - $0$ ไม่ใช่เซตว่างนะ! เช่น $\{0\}$ ถือว่ามีสมาชิก $1$ ตัว คือเลขศูนย์
> - $\{\emptyset\}$ ก็ไม่ใช่เซตว่าง! ถือว่าเป็นเซตที่มีสมาชิก $1$ ตัว คือตัวสัญลักษณ์ $\emptyset$ นั่นเอง
