# เฉลยใบงานที่ 1.2: วิธีการเขียนเซต

---

**ข้อที่ 1:**
$1.1$ ตัวอักษรซ้ำให้เขียนแค่ตัวเดียว
**ตอบ:** $F = \{m, a, t, h, e, i, c, s\}$

$1.2$ จำนวนเต็มบวกที่หารด้วย $3$ ลงตัว และไม่เกิน $15$
**ตอบ:** $G = \{3, 6, 9, 12, 15\}$

$1.3$ ใช้จุดสามจุด $\dots$ ละไว้ในฐานที่เข้าใจ
**ตอบ:** $H = \{1, 2, 3, \dots, 100\}$

---

**ข้อที่ 2:** (การเขียนแบบบอกเงื่อนไขสามารถเขียนได้หลายรูปแบบ หากความหมายตรงกันถือว่าถูกต้อง)
$2.1$ สังเกตว่า $2, 4, 6, 8, 10$ คือจำนวนคู่บวกที่น้อยกว่า $12$ (หรือน้อยกว่าหรือเท่ากับ $10$)
**ตอบ:** $J = \{x \mid x \text{ เป็นจำนวนคู่บวกที่น้อยกว่า } 12\}$ 

$2.2$ สังเกตว่า $1, 3, 5, 7, \dots$ คือจำนวนคี่บวกไปเรื่อยๆ ไม่มีที่สิ้นสุด
**ตอบ:** $K = \{x \mid x \text{ เป็นจำนวนคี่บวก}\}$
