# 1.4 การเปรียบเทียบเซต

เวลาเรามีเซต $2$ เซต เราจะเปรียบเทียบมันยังไงว่า "เหมือนกัน" หรือ "เท่ากัน"? วันนี้เราจะมาดูความแตกต่างระหว่างคำว่า **เซตที่เท่ากัน** และ **เซตที่เทียบเท่ากัน** ครับ บอกเลยว่าข้อสอบชอบเอามาหลอก!

## 1. เซตที่เท่ากัน (Equal Sets)
เซต $A$ และ $B$ จะเท่ากันได้ ก็ต่อเมื่อ **มีสมาชิก "หน้าตาเหมือนกันเป๊ะ" ทุกตัว** 
- สัญลักษณ์: $A = B$

**ตัวอย่าง:**
- $A = \{1, 2, 3\}$
- $B = \{3, 1, 2\}$
- $C = \{1, 1, 2, 3, 3\}$

จะเห็นว่า $A, B, C$ **เท่ากันทั้งหมดเลย!** 
> 💡 **ทริคจำ:** การสลับที่ หรือ การเขียนซ้ำ ไม่มีผลกับความเป็นเซต! ขอแค่มันมีสมาชิก $1, 2, 3$ เหมือนกัน ก็ถือว่าเท่ากันเป๊ะครับ

## 2. เซตที่เทียบเท่ากัน (Equivalent Sets)
เซต $A$ และ $B$ จะเทียบเท่ากันได้ ก็ต่อเมื่อ **มี "จำนวนสมาชิก" เท่ากัน** (หน้าตาไม่จำเป็นต้องเหมือนกัน ขอแค่ปริมาณเท่ากัน)
- สัญลักษณ์: $A \sim B$ หรือ $n(A) = n(B)$

**ตัวอย่าง:**
- $A = \{1, 2, 3\}$ (มีสมาชิก $3$ ตัว)
- $D = \{a, b, c\}$ (มีสมาชิก $3$ ตัว)

แบบนี้ถือว่า $A$ และ $D$ **เทียบเท่ากัน** ครับ (แต่ไม่เท่ากันนะ เพราะหน้าตาไม่เหมือนกัน)

---

## สรุปกฎเหล็ก 🛡️
- ถ้าเซต **"เท่ากัน"** ➡️ มันจะต้อง **"เทียบเท่ากัน"** ด้วยเสมอ (เพราะหน้าตาเหมือนกัน จำนวนมันก็ต้องเท่ากันอยู่แล้ว)
- แต่ถ้าเซต **"เทียบเท่ากัน"** ➡️ มัน **"อาจจะไม่เท่ากัน"** ก็ได้! (จำนวนเท่ากัน แต่หน้าตาอาจจะคนละเรื่องเลย)
