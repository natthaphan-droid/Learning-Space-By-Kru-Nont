# เซตและการดำเนินการ (Sets and Operations)

สวัสดีครับน้องๆ! วันนี้เราจะมาเรียนเรื่อง **"เซต"** กัน เรื่องนี้เป็นพื้นฐานสำคัญมากของคณิตศาสตร์ ม.ปลาย เลยนะ รับรองว่าไม่ยากอย่างที่คิด!

## เซตคืออะไร?
**เซต (Set)** คือกลุ่มของสิ่งที่เราสนใจ โดยที่เราสามารถบอกได้แน่นอนว่าสิ่งใดอยู่ในกลุ่มนั้น และสิ่งใดไม่อยู่ในกลุ่มนั้น เราเรียกสิ่งที่อยู่ในเซตว่า **สมาชิก (Element)**

> **ทริคจำง่ายๆ:** มองเซตเหมือน "กล่อง" ที่เราเอาของใส่ลงไป ของที่อยู่ในกล่องก็คือสมาชิกนั่นเอง!

### ตัวอย่าง:
- เซตของสระในภาษาอังกฤษ $A = \{a, e, i, o, u\}$
- เซตของจำนวนเต็มบวกที่น้อยกว่า 5 $B = \{1, 2, 3, 4\}$

## การดำเนินการของเซต (Set Operations)
การดำเนินการของเซต เหมือนกับการเอากล่องสองใบมาทำอะไรสักอย่างกัน มี 4 แบบหลักๆ คือ:

### 1. ยูเนียน (Union: $\cup$)
คือการเอาสมาชิกของทั้งสองเซตมา **"รวมกัน"**
$$A \cup B = \{x \mid x \in A \text{ หรือ } x \in B\}$$
**ตัวอย่าง:** ถ้า $A = \{1, 2\}$ และ $B = \{2, 3\}$
จะได้ $A \cup B = \{1, 2, 3\}$ (ตัวที่ซ้ำกันเอามาแค่ตัวเดียวนะ!)

### 2. อินเตอร์เซกชัน (Intersection: $\cap$)
คือการเอาเฉพาะสมาชิกที่ **"ซ้ำกัน"**
$$A \cap B = \{x \mid x \in A \text{ และ } x \in B\}$$
**ตัวอย่าง:** จากข้อเมื่อกี้ $A \cap B = \{2\}$

### 3. คอมพลีเมนต์ (Complement: $A'$)
คือการเอาทุกตัวในเอกภพสัมพัทธ์ ($U$) ที่ **"ไม่อยู่ใน A"**
$$A' = \{x \mid x \in U \text{ และ } x \notin A\}$$

### 4. ผลต่าง (Difference: $A - B$)
คือการเอาสมาชิกที่ **"อยู่ใน A แต่ไม่อยู่ใน B"**
$$A - B = \{x \mid x \in A \text{ และ } x \notin B\}$$
**ตัวอย่าง:** ถ้า $A = \{1, 2, 3\}$ และ $B = \{2, 3, 4\}$
จะได้ $A - B = \{1\}$ (เอาแค่เลข 1 เพราะ 2 กับ 3 มันดันไปอยู่ใน B ด้วย)

---
เป็นไงบ้างครับเรื่องเซต ไม่ยากเลยใช่ไหม! ลองจำเครื่องหมายให้แม่นๆ $\cup$ (หงาย=รวม), $\cap$ (คว่ำ=ซ้ำ) แค่นี้ก็ทำข้อสอบได้สบายแล้วครับ!
